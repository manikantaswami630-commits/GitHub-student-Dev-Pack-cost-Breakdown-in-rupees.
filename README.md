## 🚀 Getting Started & Deployment

Because this project is self-contained in a single file, you can host it instantly via **GitHub Pages**:

1. Clone or upload this repository to GitHub.
2. Ensure your main file is named `index.html`.
3. Go to your repository **Settings** -> **Pages**.
4. Set the source branch to `main` (or `master`) and save.
5. Your dashboard will be live at `https://<your-username>.github.io/<repo-name>/`.
